# Assets — BOLIVIA SLUG

Coloca aquí los recursos gráficos y de audio. Formatos recomendados: PNG (con transparencia) para sprites, MP3/OGG para audio.

| Carpeta | Qué va |
|---|---|
| `fondos/` | Fondos y capas de parallax (cielo, montañas, selva, suelo). Ej: `cielo.png`, `selva_lejana.png`, `suelo.png` |
| `personajes/jugador/` | Spritesheets del protagonista: `idle`, `correr`, `saltar`, `disparar`, `agacharse`, `morir` |
| `personajes/enemigos/` | Soldados y enemigos comunes (cada uno con sus animaciones) |
| `armas/` | Íconos o sprites de armas recogibles (pistola, metralleta, lanzacohetes, granadas) |
| `armas/proyectiles/` | Balas, cohetes, granadas |
| `jefes/` | Spritesheets de los jefes (caminar, atacar, recibir daño, morir) |
| `efectos/` | Explosiones, destellos de disparo, humo, sangre/chispas |
| `ui/` | Botones, barra de vida, íconos de munición, pantalla de título |
| `audio/musica/` | Música de fondo por nivel / jefe |
| `audio/sfx/` | Efectos de sonido: disparos, explosiones, saltos, gritos |

## Spritesheets
Para cada spritesheet, anota el tamaño de cada cuadro (ej: `64x64`) y cuántos cuadros tiene, para configurar las animaciones en Phaser.
